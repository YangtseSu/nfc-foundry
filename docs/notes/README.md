# Implementation notes

One note per completed change. A note must record:

- what was actually implemented;
- what was tested, including hardware and fixtures;
- problems encountered and how they were resolved;
- remaining blockers or follow-up work (write "none" when there are none);
- deviations from the spec and why.

Naming: `NN-short-title.md`, matching the spec where possible. Notes are
historical records; do not rewrite them as product documentation.

The previous NFCX notes are archived under `../archive/nfcx-upstream/notes/`.
