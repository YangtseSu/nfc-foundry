# Design references

Static mockups for the native UI. They are design artifacts, not production
code: the HTML is a self-contained render source, and the PNG is the reviewed
image.

## Phase 02: card workbench

- [Type 2 / NDEF workbench](02-workbench-ndef.html) — design source
- [Rendered image](02-workbench-ndef.png)

The mockup is normative for the shell structure: top context bar, left
reader/card rail, center card-family workspace with capability-driven tabs,
right inspector and persistent activity, and bottom action bar. Phase 02 builds
this shell for MIFARE Classic. The NDEF tab shown in the mockup lands in
Phase 05 and must not be filled with fake data.
